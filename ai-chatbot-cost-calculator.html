Why chatbot API estimates can be too low

A chatbot may send more than the latest user message to the model. Depending on the app, every turn can include system instructions, earlier user messages, and earlier AI replies. If the full conversation is resent each time, input-token usage can grow as the conversation gets longer.

This calculator has two context assumptions. Full previous conversation estimates the cumulative input from the system prompt and all earlier turns. Only system prompt + current message is a simpler stateless estimate. Use the option that best matches your app. Summarization, context windows, truncation, and prompt caching can change real billing.

How the estimate is calculated

Monthly conversations = active users × conversations per user
Monthly model requests = monthly conversations × user messages per conversation
Input cost = input tokens × input price per 1M ÷ 1,000,000
Budget target = (input cost + output cost) × (1 + buffer ÷ 100)

For full conversation history, the input tokens per conversation are estimated as: turns × system prompt + user-message tokens × turns × (turns + 1) ÷ 2 + AI-reply tokens × turns × (turns − 1) ÷ 2. This assumes each user message is followed by one model reply, with all earlier messages resent on the next turn.

Frequently asked questions

Does this show an exact bill?

No. It is a planning estimate based on your assumptions. Compare it with real usage after you launch, and follow your provider's billing records.

Does each turn resend the whole chat?

Not necessarily. It depends on how your application builds requests. Select the full-history option only when it resembles your implementation; otherwise use the current-turn estimate or adapt the inputs.

Are prices updated automatically?

No. Rates are manually entered so you can see and verify the assumptions. Always check official pricing before making budget decisions.

Do I need an API key?

No. All calculations run in this page in your browser; the calculator does not call the model provider.

How much does an AI chatbot cost per user?

There is no universal price per user. It depends on active users, conversations per month, message and reply length, the model's input/output rates, and whether chat history is resent. Use the per-user result above as a scenario estimate, then compare it with real usage once the app is running.

Why can longer conversations cost more?

If the application resends all earlier messages on each turn, later requests contain more input tokens than early requests. If the app uses summaries, truncates history, or has provider-specific caching, the actual token pattern can be different.
